🚀 ขั้นตอนการ Deploy (Step by Step)

1Build Assets ที่เครื่อง Local ก่อน

รันคำสั่งนี้ที่เครื่อง local เพื่อสร้างไฟล์ CSS/JS สำหรับ production:

npm install
npm run build

จะได้โฟลเดอร์ public/build/ — ต้องอัพโหลดขึ้น server ด้วย

2อัพโหลดไฟล์ขึ้น Server

อัพโหลดทุกไฟล์ ยกเว้น โฟลเดอร์และไฟล์เหล่านี้:

node_modules/     ← ใหญ่มาก ไม่จำเป็น
.env              ← ห้ามอัพ (ข้อมูล sensitive)
storage/logs/     ← ไม่จำเป็น

โครงสร้างบน server ที่แนะนำ:

/var/www/greenpaw/          ← root โปรเจกต์ (ห้าม expose)
    app/
    bootstrap/
    config/
    database/
    public/                 ← Document Root ของ web server
        build/              ← ไฟล์จาก npm run build
        index.php
        .htaccess
    resources/
    routes/
    storage/
    vendor/
    .env                    ← สร้างใหม่บน server
3ติดตั้ง PHP Dependencies บน Server
cd /var/www/greenpaw
composer install --optimize-autoloader --no-dev

--no-dev ตัด package สำหรับ testing ออก ลดขนาดและเพิ่มความปลอดภัย

4สร้างและตั้งค่าไฟล์ .env

สร้างไฟล์ .env บน server โดย copy จาก .env.example แล้วแก้ค่าดังนี้:

APP_NAME="GreenPaw Systems"
APP_ENV=production
APP_KEY=                         # ← สร้างด้วยคำสั่งด้านล่าง
APP_DEBUG=false                  # ← ต้องเป็น false เสมอ
APP_URL=https://yourdomain.com   # ← domain จริงของคุณ

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=greenpaw_db
DB_USERNAME=db_username
DB_PASSWORD=db_password

SESSION_DRIVER=file
CACHE_STORE=file
FILESYSTEM_DISK=local
APP_TIMEZONE=Asia/Bangkok

จากนั้นสร้าง APP_KEY:

php artisan key:generate
🔴 ห้ามลืม: APP_DEBUG=false บน production เด็ดขาด หากเปิดไว้จะ expose ข้อมูล database, config, และ stack trace ให้ผู้ใช้ทั่วไปเห็นได้
5ตั้งค่า Database

กรณี Server ใหม่ (DB ว่าง)

php artisan migrate --force
php artisan db:seed --force

กรณีใช้ DB เดิมจาก Vanilla PHP (greenpaw_db เดิม)

# ตรวจสอบ tables ครบก่อน แล้วรัน seed เพื่อสร้าง admin account
php artisan db:seed --force

รีเซ็ต password admin ให้ตรงกับที่ต้องการ:

php artisan tinker
>>> App\Models\User::where('username','admin')->update(['password'=>bcrypt('YOUR_PASSWORD')])
>>> exit
6สร้าง Storage Symlink

ทำให้รูปสินค้าที่ upload เข้าถึงได้จาก URL:

php artisan storage:link

จะสร้าง public/storage → storage/app/public

7ตั้งค่า Permissions (Linux) 
chmod -R 775 storage bootstrap/cache
chown -R www-data:www-data storage bootstrap/cache
ℹ️ บน shared hosting หรือ cPanel ให้ตั้ง permission folder storage/ และ bootstrap/cache/ เป็น 755 ผ่าน File Manager
8Optimize สำหรับ Production

รันคำสั่งเดียวเพื่อ cache ทุกอย่าง:

php artisan optimize

คำสั่งนี้จะรวม: config:cache + route:cache + view:cache + event:cache

⚙️ ตั้งค่า Web Server

Apache (.htaccess พร้อมใช้แล้วใน public/)

ต้องเปิด mod_rewrite และตั้ง VirtualHost:

<VirtualHost *:80>
    ServerName yourdomain.com
    DocumentRoot /var/www/greenpaw/public

    <Directory /var/www/greenpaw/public>
        AllowOverride All
        Require all granted
    </Directory>
</VirtualHost>

Nginx

server {
    listen 80;
    server_name yourdomain.com;
    root /var/www/greenpaw/public;
    index index.php;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.3-fpm.sock;
        fastcgi_index index.php;
        include fastcgi_params;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

✅ Checklist ก่อน Go-Live

  • APP_DEBUG=false ใน .env
  • APP_ENV=production ใน .env
  • APP_KEY ถูก generate แล้ว
  • DB_DATABASE, DB_USERNAME, DB_PASSWORD ถูกต้อง
  • php artisan migrate รันสำเร็จ
  • php artisan db:seed รันสำเร็จ (มี admin account)
  • php artisan storage:link รันแล้ว
  • Permissions storage/ และ bootstrap/cache/ ถูกต้อง
  • php artisan optimize รันแล้ว
  • Document Root ชี้ที่ public/ ถูกต้อง
  • HTTPS ตั้งค่าแล้ว (แนะนำ Let's Encrypt)
  • ทดสอบ login ด้วย admin และ staff
  • ทดสอบ upload รูปสินค้า
  • ทดสอบ POS checkout
  • ทดสอบว่า Staff เข้า /admin/* ไม่ได้ (403)
