1. สิทธิ์การใช้งาน (Role)

สิทธิ์หน้าที่เข้าถึงได้ข้อจำกัด
Admin ADMIN ทุกหน้าในระบบ (POS, Dashboard, สินค้า, สต็อก, บิล, รายงาน, พนักงาน) —
Staff STAFF POS (ขายสินค้า), Dashboard (ดูยอดขาย), โปรไฟล์ เข้า /admin/* ไม่ได้ จะได้รับ Error 403

2. การเข้าสู่ระบบ (Login)

เปิด browser แล้วไปที่ URL ของระบบ จะเข้าสู่หน้า Login อัตโนมัติ

🔐 หน้า Login
ชื่อผู้ใช้ (Username)
admin
รหัสผ่าน (Password)
••••••••
ℹ️ บัญชีเริ่มต้น: username = admin / password = password (แนะนำให้เปลี่ยนทันทีหลัง login ครั้งแรก)
💡 ติ๊ก "จดจำฉัน" เพื่อให้ระบบจำ session ไว้นานขึ้น ไม่ต้อง login ใหม่ทุกครั้ง

3. หน้าหลัก (Home) ทุกคน

หลัง login จะเข้าสู่หน้าหลัก แสดงเมนูตามสิทธิ์ของแต่ละ role

  • 🛒 งานขาย (POS) — เปิดหน้าจอขายสินค้า
  • 📊 สรุปภาพรวม — Dashboard ยอดขายวันนี้
  • ⚠️ แจ้งเตือนสต็อกใกล้หมด — แสดงสินค้าที่เหลือน้อยกว่า 5 ชิ้น (ถ้ามี)

4. ระบบขายหน้าร้าน (POS) ทุกคน

🔍ค้นหาสินค้า
➕ใส่จำนวน & เพิ่มลงตะกร้า
🛒ตรวจสอบตะกร้า
💰ชำระเงิน / ปิดบิล

วิธีใช้งาน

  1. พิมพ์ชื่อสินค้าในช่อง "ค้นหา" ด้านบนเพื่อกรองสินค้า
  2. ใส่จำนวนในช่องตัวเลขหน้าสินค้า (default = 1) รองรับทศนิยม เช่น 0.5 กก.
  3. กดปุ่ม "+ ใส่" เพื่อเพิ่มสินค้าลงตะกร้าด้านขวา
  4. ตรวจสอบรายการในตะกร้า — กด ✕ เพื่อลบรายการที่ไม่ต้องการ
  5. กดปุ่ม "💰 ชำระเงิน / ปิดบิล" เพื่อยืนยันการขาย
⚠️ สินค้าที่ขึ้นว่า "🚫 สินค้าหมด" ไม่สามารถเพิ่มลงตะกร้าได้ ต้องเติมสต็อกก่อน (Admin เท่านั้น)
💡 ระบบจะตัดสต็อกและบันทึก StockLog อัตโนมัติทุกครั้งที่ปิดบิล

5. Dashboard ภาพรวมยอดขาย ทุกคน

แสดงสรุปผลการขายของวันปัจจุบัน

ข้อมูลที่แสดงรายละเอียดมองเห็น
จำนวนบิลวันนี้นับเฉพาะบิล normal (ไม่รวม void)ทุกคน
ยอดขายรวมวันนี้รวมทุกบิลปกติทุกคน
ค่าฝากขายยอดที่หักให้ร้านที่รับฝากAdmin
กำไรสุทธิยอดขาย − ต้นทุน − ค่าฝากAdmin
กราฟ 7 วันย้อนหลังเส้นกราฟยอดขายรายวันทุกคน
สต็อกใกล้หมดสินค้าที่เหลือ ≤ 5 ชิ้นทุกคน
5 อันดับขายดีสินค้าที่ขายได้มากที่สุดตลอดกาลทุกคน

6. จัดการสินค้า Admin

เมนู: 🌱 สินค้า → แสดงรายการสินค้าทั้งหมด

เพิ่มสินค้าใหม่

  1. กดปุ่ม "➕ เพิ่มสินค้าใหม่" มุมบนขวา
  2. อัพโหลดรูปภาพ (ไม่บังคับ) — รองรับ jpg, jpeg, png, webp ขนาดไม่เกิน 2MB
  3. กรอกชื่อสินค้าและเลือกหมวดหมู่
  4. เลือกประเภท:
    • 🌱 สินค้าผลิตเอง — ใส่ต้นทุนย่อย (เมล็ด, ดิน, กระถาง, ค่าแรง, waste%) ระบบคำนวณต้นทุนให้อัตโนมัติ
    • 📦 สินค้าซื้อมาขายไป — ใส่ราคาทุนที่ซื้อมาตรงๆ
  5. ใส่ค่าฝากขาย (ถ้ามี) และราคาขาย
  6. กด "✅ สร้างรายการสินค้า"
ℹ️ สต็อกเริ่มต้น = 0 เสมอ ต้องเติมสต็อกแยกต่างหากที่เมนู 📥 สต็อก

แก้ไข / ลบสินค้า

  • กด "แก้ไข" เพื่อแก้ไขข้อมูลสินค้า (รูปภาพจะอัพเดตเฉพาะเมื่ออัพโหลดใหม่)
  • กด "ลบ" เพื่อลบสินค้าออกจากระบบ (รูปภาพจะถูกลบด้วย)
  • ปิดสถานะเป็น Inactive เพื่อซ่อนจาก POS โดยไม่ต้องลบข้อมูล

7. จัดการหมวดหมู่ Admin

เมนู: 🌱 สินค้า → ลิงก์ "จัดการหมวดหมู่" หรือตรงไปที่ /admin/categories

  • พิมพ์ชื่อหมวดหมู่ในช่องด้านบน กด "➕ เพิ่มหมวดหมู่"
  • กด "ลบ" เพื่อลบหมวดหมู่ (ไม่กระทบสินค้าที่อยู่ในหมวดนั้น)

8. จัดการสต็อก Admin

เมนู: 📥 สต็อก

เติมสต็อก

  1. ค้นหาสินค้าที่ต้องการในช่องค้นหา
  2. ใส่จำนวนที่ต้องการเพิ่มในช่อง (รองรับทศนิยม)
  3. กด "+ เพิ่มเข้าคลัง"
  4. ระบบจะบันทึก StockLog โดยอัตโนมัติ
ℹ️ สินค้าที่มีสถานะ "เลิกจำหน่าย" ไม่สามารถเติมสต็อกได้

ดูประวัติสต็อก

กดปุ่ม "📜 ดูประวัติสต็อก" มุมบนขวา — แสดงประวัติทุกการเคลื่อนไหวของสต็อก 200 รายการล่าสุด ทั้งรับเข้า (+) และจ่ายออก (−)

9. ประวัติการขาย & ยกเลิกบิล Admin

เมนู: 📝 ประวัติขาย

ค้นหาบิล

  • เลือกช่วงวันที่ "ตั้งแต่วันที่" ถึง "ถึงวันที่" แล้วกด "🔍 ค้นหา"
  • Default แสดงบิลของวันนี้

ดูรายละเอียดในบิล

กดปุ่ม "👁️ รายการ" เพื่อดู popup แสดงสินค้าทุกรายการในบิลนั้น

ยกเลิกบิล (Void)

  1. กดปุ่ม "🚫 Void" ท้ายแถวบิลที่ต้องการยกเลิก
  2. ระบบจะถามยืนยัน — กด OK
  3. บิลจะถูกทำเครื่องหมาย "ยกเลิกแล้ว" และสต็อกสินค้าจะถูกคืนเข้าคลังอัตโนมัติ
⚠️ บิลที่ void แล้วไม่สามารถ void ซ้ำได้ และไม่ถูกนับในยอดรายงาน

10. รายงานกำไร Admin

เมนู: 📈 รายงาน

  1. เลือก เดือน และ ปี ที่ต้องการ กด "🔍 ดูข้อมูล"
  2. ระบบแสดงสรุป 5 ตัวเลข: รายรับรวม, ค่าฝากขาย, รายรับสุทธิ, ต้นทุน, กำไรสุทธิ
  3. กราฟเส้นแสดงยอดขายรายวันตลอดเดือน
  4. กด "🖨️ พิมพ์รายงาน" เพื่อ print หรือบันทึกเป็น PDF
ℹ️ ตัวเลขทั้งหมดหักบิลที่ Void ออกแล้ว

11. จัดการพนักงาน Admin

เมนู: 👥 พนักงาน

เพิ่มพนักงานใหม่

  1. กรอก Username, ชื่อ-นามสกุล, รหัสผ่าน
  2. เลือกสิทธิ์: Staff (ขายได้อย่างเดียว) หรือ Admin (จัดการระบบได้)
  3. กด "✅ สร้างบัญชีผู้ใช้"

แก้ไขข้อมูลพนักงาน

  • กด "แก้ไข" ท้ายแถว — แก้ได้ทั้งชื่อ, สิทธิ์ และรหัสผ่าน
  • เว้นว่างช่องรหัสผ่าน หากไม่ต้องการเปลี่ยน

ลบพนักงาน

  • กด "ลบ" ท้ายแถว — ไม่สามารถลบบัญชีของตัวเองได้

12. ตั้งค่าโปรไฟล์ ทุกคน

คลิกชื่อผู้ใช้ที่ navbar มุมขวาบน → "⚙️ ตั้งค่าโปรไฟล์"

ส่วนทำอะไรได้
ข้อมูลโปรไฟล์แก้ไข Username และ ชื่อ-นามสกุล
เปลี่ยนรหัสผ่านใส่รหัสผ่านปัจจุบัน + รหัสผ่านใหม่ + ยืนยัน
ลบบัญชีลบบัญชีตัวเองออกจากระบบถาวร (ยืนยันด้วยรหัสผ่าน)
